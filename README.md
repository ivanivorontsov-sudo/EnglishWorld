# EnglishWorld

**Голосовой самоучитель английского языка для Android — от A1 к B2.**

Главная идея: не только читать правила, а регулярно говорить. Пользователь задаёт вопросы голосом или текстом, ИИ отвечает, объясняет важные ошибки и поддерживает диалог следующим вопросом. Классические уроки, карточки и прогресс дополняют разговорную практику.

## Что реализовано в первой версии

- **Голосовой режим:** системный Android SpeechRecognizer, частичная расшифровка, отправка вопроса ИИ и озвучивание ответа через Android Text-to-Speech.
- **Два способа подключения ИИ:**
  - Встроенные WebView-чаты Qwen, ChatGPT, Gemini, Grok и Copilot. Пользователь входит в свой аккаунт на официальном сайте. EnglishWorld вводит реплику в поле чата и считывает ответ — подход повторяет экспериментальный механизм из репозитория krasivyj-launcher.
  - Любой OpenAI-compatible Chat Completions API с пользовательскими HTTPS URL, названием модели и ключом.
- **Курс A1–B2:** 32 занятия, по восемь на каждый уровень; в каждом есть разговорное задание.
- **Повторение:** карточки со spaced repetition — интервалы увеличиваются при успешном вспоминании.
- **Локальный прогресс:** выполненные уроки и интервалы карточек хранятся на устройстве.
- **Приватность:** приложение не имеет своего сервера, не содержит общего API-ключа, не отправляет историю разработчику и не сохраняет историю диалога между запусками.

## Методика обучения

Программа опирается на подход Paul Nation *The Four Strands*: сбалансированное время на четыре направления:

1. Понимание английского на слух и чтение (meaning-focused input).
2. Активная речь и формулирование собственных мыслей (meaning-focused output).
3. Целенаправленная работа над грамматикой, лексикой и произношением (language-focused learning).
4. Развитие беглости через повторные попытки и содержательные задания (fluency development).

Рекомендуемый короткий ежедневный цикл — около 20 минут: 5 минут входящего английского, 5 минут собственного ответа, 5 минут фокусной работы над языком, 5 минут свободной речи или повторной попытки. Карточки используют интервальное извлечение из памяти.

Критерии цели B2 ориентируются на CEFR и Cambridge B2 First Speaking: диапазон грамматики и лексики, связность развёрнутого ответа, произношение, интерактивное общение и способность поддерживать аргументированную дискуссию. Приложение не выдаёт официальный сертификат и не обещает автоматически присвоить CEFR-уровень.

## Настройка ИИ

### Вариант 1 — веб-чат

Открой вкладку **Говорить**, выбери сервис в настройках и войди в свой аккаунт прямо в верхнем окне. Сессия остаётся в локальном Android WebView. Приложение не запрашивает пароль отдельно и не передаёт cookies на собственный сервер.

Веб-сайты могут менять разметку или ограничивать работу во встроенном WebView. При изменении интерфейса автоматическое заполнение или чтение ответа может перестать работать. Это ограничение автоматизации сайтов, а не гарантия постоянной совместимости.

### Вариант 2 — OpenAI-compatible API

В настройках укажи HTTPS Base URL, название модели и личный API-ключ. Ключ шифруется AES-GCM с ключом Android Keystore и хранится в приватных настройках приложения. Он не включён в исходный код и не передаётся разработчику.

Для Pollinations текущий API использует адрес https://gen.pollinations.ai/v1; запросы генерации требуют действующей авторизации. Не полагайся на старый text.pollinations.ai/openai как на гарантированно анонимный endpoint. См. официальную документацию: https://gen.pollinations.ai/docs.

В репозитории нет общего ключа, прокси-сервера или встроенной оплаты. Стоимость, доступность моделей, лимиты и обработка запросов зависят от выбранного провайдера.

## Голос и приватность

- Ввод использует Android SpeechRecognizer. Если устройство и служба поддерживают on-device recognition, приложение предпочитает этот вариант. Иначе Android использует доступную системную службу, которая может отправлять аудио на сервер — это зависит от устройства, службы и языкового пакета.
- Ответы озвучивает Android TextToSpeech.
- В настройках можно выбрать американский (en-US) или британский (en-GB) вариант распознавания.
- Приложение не сохраняет голосовые записи и переписку. Текст запроса отправляется выбранному ИИ-провайдеру.
- В WebView пользователь входит на сайт провайдера самостоятельно; cookies остаются в локальном хранилище WebView.

## Сборка и CI

Требуются JDK 17, Android SDK platform 35, Build Tools 35.0.0 и Gradle 8.9.

Для локальной сборки запусти: gradle testDebugUnitTest assembleDebug.

APK: app/build/outputs/apk/debug/app-debug.apk.

GitHub Actions запускает unit-тесты, собирает установочный debug APK и прикладывает его к запуску workflow. Debug APK предназначен для тестирования, а не для публикации в магазинах.

### Подписанный production-релиз

Для публикации production APK владелец проекта должен создать собственный upload keystore и добавить в GitHub Actions Secrets:

- ENGLISHWORLD_KEYSTORE_BASE64
- ENGLISHWORLD_STORE_PASSWORD
- ENGLISHWORLD_KEY_ALIAS
- ENGLISHWORLD_KEY_PASSWORD

Закрытый ключ нельзя коммитить в репозиторий или присылать в открытом виде. Пока эти секреты не настроены, CI не может выпустить production APK с подписью автора. Release workflow проверяет наличие ключа и публикует APK только для тега v*.
