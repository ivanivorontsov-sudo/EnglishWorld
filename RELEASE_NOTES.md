# EnglishWorld 0.1.0 — первая Android-версия

- Голосовой ввод английской речи и озвучивание ответов.
- WebView-режимы Qwen, ChatGPT, Gemini, Grok и Copilot с отдельным полноэкранным окном входа; сам диалог отображается в интерфейсе EnglishWorld без предпросмотра сайта.
- OpenAI-compatible API с собственными URL, моделью и зашифрованным ключом.
- 32 занятия уровней A1–B2.
- Интервальные карточки и локальное сохранение прогресса.
- Учебный диалоговый prompt с коррекцией ошибок и продолжением разговора.
- Unit-тесты учебного движка и GitHub Actions для сборки APK.

Ранний тестовый релиз. Это не официальный сертификат B2 и не production-подпись автора, пока не настроен личный release keystore.
